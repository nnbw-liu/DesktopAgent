# R1.2 UI 手动验收清单（WebView2 真机）

> 目的：bUnit 覆盖不到 WebView2 里的真实交互（JS、拖拽、下拉、停止生成）。本清单在真机上逐条走查。
> 自动化部分：`tests/SDemo.DesktopAgent.UI.Tests`（bUnit，29 个用例）。
> 截图基线：`docs/reports/ui-baseline/`（组件渲染基线，见文件头 README 说明）。

## 0. 环境

- [ ] 启动 WPF 宿主（`dotnet run --project src/Hosts/Wpf`），确认 WebView2 渲染正常、主题跟随系统。
- [ ] 准备两个工作区：一个空仓库、一个本仓库（用于压缩与引用）。

## 1. 上下文占用环（ContextMeter / ContextBreakdown）

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1.1 | 新聊天室发一句短消息 | 占用环显示 `估算 / 预算`，比例很低 | ☐ |
| 1.2 | 连续多轮对话把估算推到 80% 以上 | 占用环变为告警色（`is-warn`），数字与分段之和一致 | ☐ |
| 1.3 | 继续推到 95% 以上 | 占用环变为危险色（`is-danger`） | ☐ |
| 1.4 | 点击占用环 | 弹出分段明细：系统 / 技能 / 工具 schema / 知识库 / 历史 / 摘要 / 状态包 / 附件 / 轨迹 / pin | ☐ |
| 1.5 | 对比明细各段之和与弹层顶部总估算 | 误差 ≤ 1（取整） | ☐ |
| 1.6 | 触发一次自动压缩后重看明细 | 出现「摘要成本（累计）：输入 … / 输出 … token」 | ☐ |
| 1.7 | 关闭占用环（设置 → 上下文 → 显示占用环） | 输入框下方不再显示，其余功能正常 | ☐ |

## 2. 压缩与 pin（CompactionDivider / ChatRoom）

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 2.1 | 在 8K 模型下把会话堆到触发压缩 | 消息列表顶部出现「已压缩 N 条历史」分隔线 | ☐ |
| 2.2 | 点击分隔线 | 打开只读原文弹层，原文一条不少 | ☐ |
| 2.3 | 关闭弹层 | 会话内容不变，摘要仍生效 | ☐ |
| 2.4 | 对一条消息点「pin」 | 出现 pin 标记；再次触发压缩后该条仍以原文发送 | ☐ |
| 2.5 | 取消 pin | 标记消失，下一轮可被摘要覆盖 | ☐ |
| 2.6 | 会话菜单「压缩现在」 | 生成 / 更新摘要并刷新分隔线；兜底摘要显示「自动摘要」 | ☐ |
| 2.7 | 会话菜单「清空摘要」 | 分隔线消失，历史重新按预算裁剪 | ☐ |

## 3. 验证徽标（VerificationBadge）

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 3.1 | 让模型改一个文件（不自动验证） | 出现「未验证改动：N 个文件」+「运行验证」 | ☐ |
| 3.2 | 点击「运行验证」且构建通过 | 徽标消失，消息区不报错 | ☐ |
| 3.3 | 制造一个编译错误后运行验证 | 徽标变红并显示首条问题；模型可继续修复 | ☐ |
| 3.4 | 未配置构建 / 测试命令时点击 | 提示先去设置里配置 | ☐ |

## 4. 引用来源 chip（M3）

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 4.1 | 归档 ≥ 3 条工作区会话后，问「上次关于沙箱 ACL 的结论」 | 助手消息下方出现引用 chip（标题 + 日期） | ☐ |
| 4.2 | 点击 chip | 打开对应的原会话，且内容与引用一致 | ☐ |
| 4.3 | 引用会话已删除时点击 | 给出可读提示，不崩溃 | ☐ |

## 5. 输入区交互

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 5.1 | 打开模型选择器并切换模型 | 选中项高亮，占用环按新模型窗口重算 | ☐ |
| 5.2 | 拖拽一个 `.pdf` / 图片到输入框 | 出现附件 chip；发送后模型能看到摘要 / 路径 | ☐ |
| 5.3 | 生成中点「停止」 | 立即停止；已生成内容保留；排队审批全部取消 | ☐ |
| 5.4 | 生成中再按发送 | 被忽略，不产生第二条并发请求 | ☐ |
| 5.5 | 生成失败（断网 / 401） | 气泡内显示可读错误，不丢已生成内容 | ☐ |

## 6. 设置页（R1.4 新增项）

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 6.1 | 设置 → 上下文 → 路由模型 | 可选「摘要模型 / 当前会话模型（默认）」或具体 provider·model；保存后 settings.json 出现 `routingProviderId` / `routingModelId` | ☐ |
| 6.2 | 设置 → 模型 → 用量与成本 | 按 provider / model 列出调用数、输入 / 输出 token；未配价显示「未配价」，不显示 0 元 | ☐ |
| 6.3 | 在 settings.json 给模型补 `inputPricePerMillion` / `outputPricePerMillion` 后刷新 | 金额出现；合计在全部模型配价时给出 | ☐ |
| 6.4 | 助手消息展示「审批 N 次」 | 与真实弹窗次数一致（评测的自动审批不计入） | ☐ |
