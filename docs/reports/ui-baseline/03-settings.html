预算与裁剪

每次请求都会先估算 token 并按预算裁剪；原始消息不会被删除，只是不发送。

预算占窗口比例 0.1 – 0.95；默认 0.85，越大越激进。
保留最近轮次 普通模型 / ≤8K 小模型分别设置；其余历史交给摘要。 /
工具轨迹回放预算 每条助手消息最多回放多少 token 的工具轨迹。
附件内联上限 当前轮附件最多内联多少 token；超出只留文件名与路径。
pin 数量上限 pin 的消息永不淘汰 / 压缩；默认 20 条。

压缩与摘要

超预算时先把较早历史压成摘要，再按预算裁剪。摘要失败会自动退回确定性摘要，不会阻塞回答。

摘要模型 默认使用当前会话模型；可指定更便宜的模型。
摘要上限 摘要正文 token 上限；默认 800。
单次摘要输入上限 超过就分块增量摘要；默认 6000 token。
摘要超时 秒；超时 / 5xx / 格式不符都会走确定性兜底。

工作记忆状态包

每轮把「工作区结构、最近改动、最近工具动作、验证状态」放进系统块；由宿主生成，不调用模型。

状态包上限 普通模型 / ≤8K 小模型（默认 800 / 500 token）。 /

工具路由模型

规则看不出该给哪些工具时，才用这个模型做一次结构化路由；超时 / 失败 / 输出非法都会自动回落规则，不影响对话。

路由模型 默认复用摘要模型，没有摘要模型时用当前会话模型。
路由超时 秒；超时直接回落规则，不重试。

高级

排查预算异常时再动这里；默认值适合大多数情况。

单条工具结果上限 工具循环内单条结果保留的字符数。
