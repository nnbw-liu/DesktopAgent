## 4. 推荐档位

| 用途 | 推荐 | 依据 |
| --- | --- | --- |
| 单文件、公开 API、小改动 | 8B / 32K | T01/T08 在 8B 下可过；但补丁仍不稳 |
| 外部仓库多文件定位 | ≥14B 或云端 32K | 8B 在 T02–T07 反复搜索/补丁失败；4B 8K 基本不可用 |
| 8K 小模型演示 | 4B / 8K，仅限极短任务 | P6 3/5；P7 外部仓库 1/8 |
| 生产建议 | 云端 32K 或本机 14B+（11GB VRAM 需 Q4 + KV 量化） | 本机 8B 已占 10.7GB，14B 需更激进的量化 |

## 5. 不可外推的结论

- P7 单次运行、每任务一次；没有双跑方差，不能声称“稳定 1/8”。
- 8K 配置的 LM Studio 实际加载上下文被模型默认配置覆盖（`lms ps` 显示 162560），Agent 侧仍按 8K 预算裁剪；不要把加载窗口当成评测窗口。
- T07 的私有方法名验收、T05/T06 的测试名检查会放大失败率；行为级任务的表现应单独评估。
- 评测使用自动审批，P7 的“审批 ≤2 次”没有实测，不能引用为产品指标。
