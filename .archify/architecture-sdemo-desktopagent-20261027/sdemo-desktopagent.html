分层依赖顺序（单向）

  • Contracts 位于最底层，零依赖，所有层可引用
  • 能力层：Editing / Context / Execution / Sandbox / Agents / Plugins
  • Tools.* 工具包聚合在能力层之上
  • Storage 只被组合根与能力层消费
  • Core 是唯一组合根，向上被 UI / Hosts 引用

双宿主策略

  • WPF 为主入口，MAUI 覆盖 Windows（默认）与 Android（可选）
  • 两者共享 SDemo.DesktopAgent.UI 的 Razor 组件
  • 差异收敛到 5 个平台接口，不扩散到业务层
  • 平台实现集中在 Execution.Windows / Sandbox.Windows / Tools.Windows
  • 由 SDemo.DesktopAgent.Windows 统一注册

Agent 与插件体系

  • 入口唯一：IAgentRuntime（src/Agents）
  • 基于 Microsoft.Agents.AI 1.25.0
  • 插件链：Abstractions → Runtime → 内置插件
  • 内置插件以嵌入资源随包分发
  • 插件提示词由 Runtime 统一组装

沙箱与安全

  • Sandbox.Contracts 保持零依赖协议
  • 平台中立层与 Windows 实现分离
  • 隔离手段：AppContainer / Job Object / Windows Sandbox
  • 独立测试工程 SDemo.DesktopAgent.Sandbox.Tests
