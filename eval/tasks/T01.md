# 拒绝非正的帮助显示宽度

## 需求

`ParserSettings.MaximumDisplayWidth` 目前允许设置为 0 或负数，之后帮助文本排版会出现不可预期的换行。请让这个属性在赋值时拒绝小于 1 的值，并抛出 `ArgumentOutOfRangeException`；合法值仍应正常保存。不要改变其他设置项或帮助文本的既有行为。

## 完成标准

- 设置为 0 或负数时抛出 `ArgumentOutOfRangeException`。
- 设置为 80 等合法值时正常保存。
- 既有测试全部通过。
