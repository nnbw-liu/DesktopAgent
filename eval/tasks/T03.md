# 拒绝非正的 HelpText 显示宽度

## 需求

`HelpText.MaximumDisplayWidth` 是公开可写属性，但传入 0 或负数时不会报错，只会在生成帮助文本时产生异常排版。请让赋值小于 1 时立即抛出 `ArgumentOutOfRangeException`，合法值保持原行为。不要修改构造函数的默认宽度推断逻辑。

## 完成标准

- `MaximumDisplayWidth = 0` 和 `= -10` 都抛出 `ArgumentOutOfRangeException`。
- `MaximumDisplayWidth = 40` 能正常保存并用于帮助文本。
- 既有测试全部通过。
